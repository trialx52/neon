Made to roam

A companion with a little motion.

Neon lives on your Windows desktop, with playful movement and controls you can tune to your setup.

✳

Wanders around

Neon patrols desktop icons, hops about, and can crawl along screen edges.

◉

Make it yours

Adjust glow color, movement pace, speech settings, and auto-feed from Neon’s settings.

⌁

Speaks and reacts

Use speech preview and one-time voice commands through Windows speech services.

Quick setup

Bring Neon home.

The download includes the Python app and its animation assets.

01 / DOWNLOAD

Get the package

Download neon.zip and extract it to a folder.

02 / REQUIREMENTS

Use Python 3

Install Python 3 for Windows. Pillow is optional for extra movement effects.

03 / LAUNCH

Start your companion

Open PowerShell in the extracted folder and run:
python .\neon_pet.py

About junk snacks: Neon’s optional auto-feed can remove eligible older files from your user temporary folder. Review the feed settings before enabling it.
